# Telegram-бот поздравлений с днём рождения

Админ-бот сохраняет именинников и ежегодно публикует поздравительную открытку в выбранный Telegram-канал. Фотография автоматически помещается под PNG-дизайн с прозрачным вырезом.

## Возможности

- пошаговое добавление: фото → имя → дата → должность/специализация → филиал;
- выбор филиала готовой inline-кнопкой;
- ежегодное повторение поздравлений (переносить записи на следующий год не нужно);
- публикация по умолчанию в 09:00 в часовом поясе `Asia/Tashkent`;
- настройка канала, времени, PNG-шаблона и текста прямо внутри бота;
- готовое предпросмотр-сообщение: открытка и финальный текст отправляются вместе;
- если в один день 2–9 именинников, бот публикует один альбом с общим текстом; начиная с 10 человек создаются следующие альбомы по 9 фотографий;
- списки именинников на текущий и следующий месяц;
- общий предпросмотр по каждому дню: одиночная открытка или альбом до 9 фотографий с итоговым текстом; для 10 и более человек предпросмотр разбивается на несколько альбомов;
- список всех записей и редактирование фото, имени, даты, должности и филиала;
- главный администратор `426250217` и назначаемые внутри бота модераторы с тем же рабочим функционалом;
- закреплённая панель содержит только «Новый именинник», «Именинники» и «Настройки»; кнопка «Модераторы» показывается только главному администратору, а филиалы находятся внутри настроек;
- безопасное удаление и запрет удаления занятого филиала;
- журнал публикаций, защита от повторного поста и повторные попытки при ошибке;
- встроенный стартовый дизайн 1080×1080 — его можно сразу заменить своим PNG.

## Быстрый запуск

Готовая Cloudflare Workers-версия находится в каталоге [`cloudflare`](./cloudflare). Она использует Telegram webhook, D1, Workers KV и Cron Trigger, поэтому не требует постоянно работающего сервера. Подробности — в [`cloudflare/README.md`](./cloudflare/README.md).

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой числовой Telegram ID, например через [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` в `.env` и заполните:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=426250217
   TIMEZONE=Asia/Tashkent
   DATA_DIR=./data
   ```

   Главный администратор назначает дополнительных модераторов в меню **Модераторы**.

4. Запустите одним из способов.

### Docker (рекомендуется для сервера)

```bash
docker compose up -d --build
```

### Локально

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

После запуска напишите боту `/start`.

## Первичная настройка в Telegram

1. Добавьте бота администратором в канал и разрешите публикацию сообщений.
2. Откройте **Настройки → Канал публикации** и перешлите боту пост из канала. Если пересылка защищена, отправьте `@username` публичного канала или его ID вида `-100...`.
3. При необходимости откройте **Настройки → PNG-шаблон** и отправьте PNG **как документ**. При отправке как обычного фото Telegram удаляет альфа-канал.
4. Выберите один из 44 уже добавленных филиалов и заведите именинников. При необходимости список филиалов можно менять в настройках.

## Как устроен PNG-шаблон

Размер может быть любым от 300×300, рекомендуемый — 1080×1080. Загруженная фотография масштабируется с заполнением всего холста, затем PNG накладывается поверх неё. Поэтому:

- прозрачная центральная область показывает фотографию;
- непрозрачные и полупрозрачные области содержат рамку и ваш дизайн;
- итоговая открытка сохраняет размер PNG-шаблона.

Новый шаблон применяется ко всем будущим публикациям, включая уже заведённых именинников.

## Текст поздравления

В тексте доступны переменные:

- `[ФИО]` — имя и фамилия;
- `[Должность]` — должность или специализация;
- `[Филиал]` — филиал;
- `[Дата]` — день и месяц рождения.

Стандартный текст уже настроен. Разметка Telegram HTML (`<b>...</b>`, `<i>...</i>`) поддерживается.

Для нескольких именинников используется отдельный общий шаблон. Его можно изменить через **Настройки → Общий текст для группы**. Поле `[Список]` формирует естественное перечисление людей в одном предложении, `[Количество]` содержит количество людей в текущем альбоме. Старые технические переменные в фигурных скобках продолжают поддерживаться для совместимости.

Дату рождения можно вводить с точкой, дефисом или косой чертой: например `15.10`, `15-10` или `15/10`. Год необязателен.

## Надёжность и резервное копирование

Все данные находятся в папке `data/`: SQLite-база, исходные фото, шаблоны и готовые открытки. Для резервного копирования достаточно копировать эту папку. Не удаляйте её при обновлении контейнера.

Бот проверяет публикации каждую минуту. До заданного времени он ничего не отправляет, после него публикует ещё не отправленные поздравления. Это позволяет догнать публикацию после короткого перезапуска. Неудачные отправки повторяются раз в 15 минут, максимум 10 раз.

Особенность 29 февраля: поздравление публикуется 29 февраля только в високосный год.
